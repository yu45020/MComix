# Keyboard and mouse

These are the default shortcuts. Change them in **Preferences > Shortcuts**;
your changes are saved in `keybindings.conf` in the MComix config folder. A
shortcut does nothing while its action is unavailable, for example Delete
while no book is open.

## Navigation

| Action | Keys |
| --- | --- |
| Next page | Page Down, keypad Page Down |
| Previous page | Page Up, keypad Page Up, Backspace |
| Next / previous page in reading direction | Alt+Right / Alt+Left (swapped in manga mode) |
| Forward ten pages | Shift+Page Down, Shift+Alt+Right |
| Back ten pages | Shift+Page Up, Shift+Backspace, Shift+Alt+Left |
| Shift pairing forward / back (double page mode: move one page) | Ctrl+Page Down / Ctrl+Page Up, Ctrl+Backspace |
| First page / last page | Home / End |
| Go to page | G |
| Next / previous archive | Ctrl+Shift+N / Ctrl+Shift+P |
| Next / previous directory | Ctrl+N / Ctrl+P |

## Scrolling

| Action | Keys |
| --- | --- |
| Scroll down / up / left / right | arrow keys, keypad arrows |
| Smart scroll down / up | Space / Shift+Space |
| Invert smart scroll direction | X |
| Scroll to a corner, an edge or the center | keypad 1–9 with Num Lock on (laid out like the page: 7 is top left, 5 the center, 3 bottom right) |

## View

| Action | Keys |
| --- | --- |
| Fullscreen | F, F11 |
| Leave fullscreen | Escape (quits instead when **Escape key closes program** is on) |
| Double page mode | D |
| Manga mode (right to left) | M |
| Best fit / fit width / fit height / fit to size | B / W / H / S |
| Manual zoom mode | A |
| Stretch small images | Y |
| Zoom in / out | + or = / − (also keypad + and −) |
| Normal size | Ctrl+0, keypad 0 |
| Rotate 90° clockwise / counter-clockwise | R / Shift+R |
| Keep transformation across pages | K |
| Magnifying lens | L |
| Show OSD panel | Tab |
| Thumbnail sidebar | F9 |
| Show/hide menu bar | Ctrl+M |
| Show/hide all interface elements | I |
| Start slideshow | Ctrl+S |
| Minimize | N |

Rotate 180°, flips, the autorotate options, showing or hiding the toolbar,
status bar and scroll bars, and Edit archive have no default key; assign one
in Preferences if you use them.

## File and tools

| --- | --- |
| Open | Ctrl+O |
| Library | Ctrl+L |
| Close | Ctrl+W |
| Save As (extract the current page) | Ctrl+Shift+S |

| Enhance image | E |

## Mouse

| Action | Mouse |
| --- | --- |
| Next page | left click (Shift: ten pages) |
| Previous page | Alt+right click (Shift+right click: ten pages) |
| Context menu | right click |
| Scroll the page | drag with the left button |
| Magnifying lens | hold the middle button |
| Show OSD panel | extra button 4 (often the side "back" button) |
| Scroll, or smart scroll | wheel |
| Zoom in / out | Ctrl+wheel |
| Next / previous page | tilt the wheel right / left (swapped in manga mode) |
